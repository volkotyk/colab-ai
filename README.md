# colab-ai

Google Colab notebooks I use for Stable Diffusion experiments. Most of them come from other authors, and the credit goes to them.

| Notebook | What it does | Original |
|---|---|---|
| [Lora_Trainer](https://colab.research.google.com/github/volkotyk/colab-ai/blob/main/Lora_Trainer.ipynb) | Trains a LoRA with kohya-ss sd-scripts | [Hollowstrawberry](https://github.com/hollowstrawberry/kohya-colab), based on [kohya-ss](https://github.com/kohya-ss/sd-scripts) and Linaqruf |
| [Dataset_Maker](https://colab.research.google.com/github/volkotyk/colab-ai/blob/main/Dataset_Maker.ipynb) | Builds and tags an image dataset for LoRA training | [Hollowstrawberry](https://github.com/hollowstrawberry/kohya-colab) |
| [comfyui_colab_with_manager](https://colab.research.google.com/github/volkotyk/colab-ai/blob/main/comfyui_colab_with_manager.ipynb) | Runs ComfyUI with ComfyUI-Manager | [ComfyUI-Manager](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/notebooks/comfyui_colab_with_manager.ipynb) |
| [fooocus_colab](https://colab.research.google.com/github/volkotyk/colab-ai/blob/main/fooocus_colab.ipynb) | Runs Fooocus | [Fooocus](https://github.com/lllyasviel/Fooocus/blob/main/fooocus_colab.ipynb) |

Each link in the first column opens the notebook in Colab.
